# FBG Schuljahr – Konten und Verteiler

Offline-Werkzeug des Friedrich-Bährens-Gymnasiums Schwerte. Macht aus SchILD-Exporten MS365-Konten, Verteiler, Jamf-, IServ- und WebUntis-Importdateien sowie Briefe.

**Datenschutz:** Dieses Repo enthält nur das Werkzeug und erfundene Testdaten. Der Stand (`FBG_Schuljahr_Stand.json`), Exporte, erzeugte Skripte, Passwortlisten und Briefe bleiben ausschließlich auf den Schulrechnern.

Benutzung: Datei `FBG_Schuljahr.html` herunterladen und in Chrome oder Edge öffnen.
